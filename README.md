# 🌹 پیج عاشقانه (اینستاگرام + تلگرام) با انتشار خودکار توسط GitHub

**ریپو:** https://github.com/lovelife4all/kolbe-ghalb

یک سیستم کامل که **هر روز در ۳ نوبت** (۹ صبح، ۳ عصر، ۹ شب به وقت تهران) به‌صورت خودکار
یک پست عاشقانه را روی **کانال تلگرام** و **پیج اینستاگرام** منتشر می‌کند — بدون هزینه، بدون سرور.

### 🎯 تصمیم‌های قطعی‌شده

| مورد | انتخاب |
|---|---|
| موضوع محتوا | **عشق + دلتنگی**: ۱۱ عاشقانه · ۱۱ دلتنگی · ۹ نامه‌ی عاشقانه |
| زمان‌بندی | **۰۹:۰۰ / ۱۵:۰۰ / ۲۱:۰۰** به وقت تهران |
| تأمین محتوا | تولید با هوش مصنوعی (در همین گفتگو) |
| تصویر پست‌ها | صحنه‌های عاشقانه (زوج ۲۵–۳۰ ساله) + فونت وزیرمتن + چینش راست‌به‌چپِ صحیح |
| انتشار اینستاگرام | **Zernio API** — بدون اپِ فیسبوک، بدون تمدیدِ توکن |
| نام پیج | **@kolbe_ghalb** (کلبه‌ی قلب) — به عنوان امضای پایین تصویر |
| مرحله‌ی جاری | ساخت بانک محتوا ← **۳۱ پست آماده است** ✅ |
| مرحله‌ی بعد | اتصال تلگرام (ربات + کانال) |

## مرحله ۱ — هویت پیج

قبل از هر چیز باید این ۴ مورد را قطعی کنیم (در همین گفتگو انتخاب می‌کنیم):

- **اسم پیج / کانال** (کوتاه، به‌یادماندنی، ترجیحاً با یک کلمه‌ی کلیدی مثل `eshgh`, `del`, `ghalb`)
- **لحن**: شاعرانه و کلاسیک / صمیمی و امروزی / عمیق و فلسفی
- **تم رنگی**: از بین ۱۲ تم آماده → `rose, night, cream, sunset, mint, blush, wine, ocean, alone, rain, empty, farewell`
- **هشتگ‌های ثابت**

## مرحله ۲ — تلگرام (۵ دقیقه)

1. در تلگرام به [@BotFather](https://t.me/BotFather) برو و دستور `/newbot` را بفرست.
2. نام و یوزرنیم ربات را بده (یوزرنیم باید به `bot` ختم شود، مثل `eshgh_post_bot`).
3. توکنی که می‌دهد را کپی کن → این می‌شود `TELEGRAM_BOT_TOKEN`.
4. یک **کانال** تلگرامی بساز با آدرس `@kolbe_ghalb` و ربات را به عنوان **ادمین با دسترسی ارسال پیام** اضافه کن.
5. **گرفتن Chat ID:** یک پیام تست در کانال بفرست، سپس این لینک را در مرورگر باز کن:
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
   در خروجی دنبال `chat` → `id` بگرد (مثل `-1001234567890`).
   اگر کانال عمومی است، همان `@kolbe_ghalb` هم کار می‌کند.

## مرحله ۳ — اینستاگرام از طریق Zernio (۱۰ دقیقه)

**چرا Zernio؟** Graph API خودِ اینستاگرام احتیاج دارد به: ساخت اپ در فیسبوک، بررسی (App Review)،
اتصال به یک پیج فیسبوک، و تمدیدِ دستیِ توکن هر ۶۰ روز. Zernio همه‌ی این مراحل را حذف کرده —
**یک درخواست برای انتشار**، و خودش چرخشِ توکن و محدودیتِ نرخ را مدیریت می‌کند. دو حسابِ اول رایگان است.

> ⚠️ همچنان لازم است اکانت اینستاگرام از نوع **Business** یا **Creator** باشد (اکانت شخصی کار نمی‌کند).

1. **تبدیل اکانت:** Settings → Account → **Switch to Professional Account** → Creator.
2. **ثبت‌نام:** برو به [zernio.com/signup](https://zernio.com/signup) و با گوگل وارد شو.
3. **ساخت کلید API:** [dashboard → API keys](https://zernio.com/dashboard/api-keys) →
   **Create API key** → کلید را همان‌جا کپی کن (دیگر نمایش داده نمی‌شود) → این می‌شود `ZERNIO_API_KEY`.
4. **ساخت پروفایل و اتصال اینستاگرام:**
   ```bash
   export ZERNIO_API_KEY="sk_..."
   pip install -r requirements.txt

   python scripts/zernio_setup.py --new-profile "kolbe_ghalb"
   # profileId ی که چاپ می‌شود را بردار و بعد:
   python scripts/zernio_setup.py --connect <PROFILE_ID>
   ```
   لینکی که چاپ می‌شود را در مرورگر باز کن و اجازه بده.
5. **گرفتن accountId:**
   ```bash
   python scripts/zernio_setup.py
   ```
   همه‌ی حساب‌های متصل را نشان می‌دهد؛ مقدار `_id` جلوی `platform=instagram`
   همان `ZERNIO_INSTAGRAM_ACCOUNT_ID` است.
6. **تست واقعی** (بعد از اینکه ریپو روی گیت‌هاب **عمومی** شد):
   ```bash
   python scripts/zernio_setup.py --test p001 --repo USERNAME/REPO
   ```
   اگر پست روی پیج ظاهر شد، اینستاگرام وصل است. ✅

**نکته:** Zernio باید بتواند تصویر را دانلود کند، برای همین ریپوی گیت‌هاب باید **Public** باشد
(سیستم به‌طور خودکار از `raw.githubusercontent.com` استفاده می‌کند).

## مرحله ۴ — بانک محتوا (`content/posts.csv`)

هر سطر یک پست است. می‌توانی در اکسل، گوگل‌شیت یا مستقیم در گیت‌هاب ویرایشش کنی:

| ستون | توضیح |
|---|---|
| `id` | شناسه‌ی یکتا (p001, p002, …) |
| `tone` | `عاشقانه` / `دلتنگی` / `نامه` — برای تنوع در طول روز |
| `theme` | یکی از: `rose, night, cream, sunset, mint, blush, wine, ocean` |
| `text` | متن اصلی — برای رفتن به خط بعد از `<br>` استفاده کن |
| `source` | منبع (حافظ، سعدی، مولوی، سهراب، یا `اختصاصی`) |
| `hashtags` | هشتگ‌های اینستاگرام (۲۴ تا برای هر پست) |
| `caption` | کپشن کاملِ اینستاگرام (قلاب + متن + سؤالِ پایانی) |
| `image` | مسیر تصویر — اگر خالی باشد خودکار ساخته می‌شود |
| `status` | `pending` → `ready` → `published` (خودکار) |

**وضعیت فعلی:** ۳۱ پست آماده است (۱۱ عاشقانه · ۱۱ دلتنگی · ۹ نامه‌ی عاشقانه) — برای حدود **۱۰ روز** کافی است.

**تصویر پست‌ها:** هر پست به‌صورت خودکار روی یکی از ۱۲ صحنه‌ی عاشقانه‌ی
`assets/backgrounds/` ساخته می‌شود (زوجِ ۲۵–۳۰ ساله در موقعیت‌های رمانتیک)؛
متن با **ایموجیِ رنگیِ واقعی** همراه است و امضای `@kolbe_ghalb` در پایینِ **وسط** قرار می‌گیرد. روشناییِ آن‌ها یکنواخت می‌شود تا متنِ سفید
روی همه‌ی تم‌ها خوانا باشد. برای تغییر بک‌گراند، کافی است فایلِ هم‌نامِ تم را جایگزین کنی.

**نکته‌ی مهم:** ۳ پست در روز یعنی **۹۰ پست در ماه**. پس باید هر هفته حدود ۲۰–۲۵ پست جدید به فایل اضافه کنی
(یا از من بخواهی برایت تولید کنم).

**ایموجی‌ها:** تصاویر ایموجی در `assets/emoji/` هستند. برای افزودن ایموجی جدید،
فایل PNG آن را با نامِ codepoint (مثلاً `1f495.png`) در آن پوشه بگذار.

اگر می‌خواهی تصویرها را خودت طراحی کنی، فایل را در `content/images/post_pXXX.jpg` بگذار و مسیرش را در ستون `image` بنویس.

## مرحله ۵ — راه‌اندازی روی گیت‌هاب

1. یک ریپوی **Public** جدید در گیت‌هاب بساز (باید Public باشد تا اینستاگرام بتواند تصویر را دانلود کند).
2. این دستورها را در پوشه‌ی پروژه اجرا کن:
   ```bash
   git init
   git add .
   git commit -m "راه‌اندازی اولیه"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. **Settings → Secrets and variables → Actions → New repository secret** و این‌ها را اضافه کن:

   | Secret | مقدار |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | توکن ربات |
   | `TELEGRAM_CHAT_ID` | آیدی کانال یا `@channel` |
   | `ZERNIO_API_KEY` | کلید API از zernio.com |
   | `ZERNIO_INSTAGRAM_ACCOUNT_ID` | شناسه‌ی حساب (از zernio_setup.py) |

4. در تب **Variables** همین بخش:

   | Variable | مثال |
   |---|---|
   | `PAGE_SIGNATURE` | `@kolbe_ghalb` |
   | `PAGE_HASHTAGS` | `عاشقانه عشق شعر_عاشقانه جملات_عاشقانه` |
   | `IMAGE_CDN` | `raw` (یا `jsdelivr` برای سرعت بیشتر) |
   | `IG_API_VERSION` | `v23.0` |

## مرحله ۶ — تست و فعال‌سازی

1. در گیت‌هاب برو به تب **Actions** → workflow **«انتشار خودکار پست»** → **Run workflow**.
2. تیک **dry_run** را بزن و اجرا کن: هیچ پستی ارسال نمی‌شود ولی مراحل در لاگ دیده می‌شود.
3. اگر لاگ سبز بود، دوباره Run workflow بزن ولی این بار بدون dry_run → پست واقعی منتشر می‌شود.
4. از این به بعد خودکار اجرا می‌شود:

   | نوبت | ساعت تهران | کرون (UTC) |
   |---|---|---|
   | صبح | ۰۹:۰۰ | `30 5 * * *` |
   | عصر | ۱۵:۰۰ | `30 11 * * *` |
   | شب | ۲۱:۰۰ | `30 17 * * *` |

> ⏱️ **نکته:** کرونِ GitHub Actions گاهی ۵ تا ۱۵ دقیقه تأخیر دارد (مخصوصاً سر ساعتِ دقیق).
> این برای پیج عاشقانه مشکلی نیست.

## اجرای محلی (برای تست قبل از انتشار)

```bash
pip install -r requirements.txt

# ساخت تصویر همه‌ی پست‌های بدون تصویر
python scripts/make_image.py --all

# شبیه‌سازی انتشار (بدون ارسال واقعی)
python scripts/publish.py --prepare --dry-run
python scripts/publish.py --publish --dry-run

# انتشار واقعی یک پست خاص
python scripts/publish.py --id p003
```

برای دیدن پیش‌نمایش همه‌ی طرح‌ها فایل `preview.html` را در مرورگر باز کن.

## ❓ سوالات متداول

**چرا ریپو باید Public باشد؟**
چون اینستاگرام باید بتواند تصویر را از یک لینک اینترنتی دانلود کند. ریپوهای Private لینک عمومی ندارند.

**می‌توانم فقط تلگرام داشته باشم و اینستاگرام نه؟**
بله — کافی است Secretهای `IG_*` را وارد نکنی؛ سیستم فقط تلگرام را ارسال می‌کند.

**می‌توانم ویدیو/ریلز/استوری هم بفرستم؟**
بله — Zernio از ریلز، استوری و کاروسل هم پشتیبانی می‌کند و فقط باید در `mediaItems`
نوع را `video` بگذاری و `platformSpecificData` را تنظیم کنی. فعلاً روی عکس متمرکزیم.

**اگر اینترنت/سرور گیت‌هاب قطع بود چه؟**
GitHub Actions برای اجرای ناموفق، پست را `failed` علامت می‌زند و پست بعدی را بعداً می‌فرستد؛ هیچ محتوایی گم نمی‌شود.
